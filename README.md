# COMBAT ZONE
Prototipo FPS 3D para navegador.

## Controles
- WASD: movimiento
- Mouse: mirar
- Clic izquierdo: disparar
- R: recargar
- Shift: correr
- ESC: pausar

## Publicación
El sitio se publica con GitHub Pages mediante GitHub Actions.
Este prototipo requiere conexión a internet para cargar Three.js desde jsDelivr.
